✅ Работает в Telegram! Настройки → Данные и память → Прокси → Добавить прокси → SOCKS5
⚠️ Render Free спит через 15 мин бездействия. Первое подключение ~30 сек.
📖 Инструкция для Telegram
1. Настройки → Данные и память → Прокси
2. Добавить прокси → SOCKS5
3. Введи Server, Port, Username, Password
4. Сохрани → Готово!
🌐 Для браузера/ПК
Chrome: Расширение FoxyProxy
Firefox: Настройки → Сеть → Прокси → SOCKS5
Windows: Настройки → Прокси → Использовать прокси-сервер
Android: Настройки WiFi → Дополнительно → Прокси → Вручную
